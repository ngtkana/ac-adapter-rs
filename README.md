# AC Adapter

![AC Adapter Logo](contents/logo.png)

競技プログラミング用 Rust ライブラリ集。`libs/` 以下に約70個の独立したクレート（データ構造・数論・グラフアルゴリズムなど）を収録。

## 目的から探す

| このリポジトリを開発する | [DEVELOPMENT.md](DEVELOPMENT.md) |
