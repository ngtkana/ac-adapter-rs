# fast_parse_u64 ベンチマーク

## 設定

| パラメータ | 値 |
|-----------|-----|
| テストケース | 10桁, 20桁 |
| バッチ | 10,000回/反復 |

## 結果

| ケース | fast_parse_u64 | std_parse | 改善 |
|--------|---|---|---|
| 10桁 | 3.53 ns | 3.92 ns | 10% |
| 20桁 | 8.76 ns | 11.51 ns | 24% |

## 測定値

```
fast_parse_u64/10_digits ... 35289 ns/iter (+/- 851)
fast_parse_u64/20_digits ... 87616 ns/iter (+/- 1286)
std_parse_u64/10_digits  ... 39225 ns/iter (+/- 1656)
std_parse_u64/20_digits  ... 115087 ns/iter (+/- 2503)
```

## 分析

- 10桁: 小差（10%）
- 20桁: 差拡大（24%）→ 桁数増加で fast有利

## 最適化履歴

### v1: 初期実装 (2026-08-30)
