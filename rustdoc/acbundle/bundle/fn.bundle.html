Expand description

指定された全クレート＋その全内部依存をdedupし、それぞれを mod <name> { .. } として1つの syn::File にまとめ、prettyplease で整形したソースを返す。

exclude に含まれるクレート名は出力から除く（貼り付け先に既にバンドル済みで 重複定義になる場合に使う）。ただし内部参照のパス書き換えには含めたまま扱う （既に貼り付け済みの mod <name> {} が同じファイルの兄弟として存在する前提のため）。
