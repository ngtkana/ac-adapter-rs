Crate fp

Source
Expand description

素体 $𝔽_P$ の演算。四則演算・べき乗・逆元を $O(1)$ または $O(\log n)$ で計算。

§仕様

型パラメータ const P: u64 に素数を固定し、$(0, 1, \ldots, P-1)$ 上の演算を提供。 ほぼすべての操作は const fn 対応。

§例

use fp::fp;
const P: u64 = 1009;
let a = fp::<P>(123);
let b = a.pow(100); // $a^{100} \bmod P$, $O(\log n)$
let c = a / fp::<P>(456); // $a \cdot 456^{-1}$, 逆元は $O(\log P)$
assert_eq!(a * a.inv(), fp::<P>(1));

§API

  • fp(), fpu(): 要素の生成（$O(1)$）
  • +, -, *, /: 四則演算（$O(1)$）
  • pow(): べき乗（$O(\log n)$）
  • inv(): 逆元（$O(\log P)$）
