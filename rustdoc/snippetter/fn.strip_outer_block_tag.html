pub(crate) fn strip_outer_block_tag(html: &str) -> String
Expand description

要約行（1行目）は常にインライン表示したいが、# 見出しのようにMarkdownの ブロック要素（<h1>〜<h6>, <p>, <blockquote>等）としてレンダリングされることがある。 それらのタグをそのまま埋め込むと表示先の文脈（<p class="summary">等）でレイアウトが壊れるため、 最外周のブロックタグ1つだけを剥がしてテキストとして扱う。
