Crate fp_precalc

Source
Expand description

有限体 $\mathbb{F}_P$ 上の階乗・逆元・逆階乗テーブルを事前計算し、二項係数を $O(1)$ で求める。

階乗テーブルは $\mathrm{fact}i = \mathrm{fact}{i-1} \times i$ の漸化式で構築する。 逆元テーブルは $P \bmod i$ を利用した線形篩で、拡張ユークリッド互除法を使わずに構築する。 逆階乗テーブルは、逆元テーブルがあれば $\mathrm{finv}i = \mathrm{finv}{i-1} \times \mathrm{inv}_i$ で、 なければ階乗テーブルの末尾のみ拡張ユークリッドで逆元を求め、そこから逆順に $\mathrm{finv}i = \mathrm{finv}{i+1} \times (i+1)$ で埋める。いずれも $O(n)$ で、 構築後は階乗・逆元・逆階乗の参照と二項係数の計算がすべて $O(1)$ になる。

テーブルの構築有無は型パラメータ Fact, Finv, Inv（On / Off）で追跡し、 未構築のテーブルへのアクセスをコンパイル時に禁止する。

§仕様

  • 型: Precalc<const P: u64, Fact = Off, Finv = Off, Inv = Off>（容量 len、P は素数）
  • 構築（ビルダーパターン、任意の順で呼び出し可）
    • build_fact: 階乗 $n!$
    • build_inv: 逆元 $n^{-1}$
    • build_finv_using_inv: 逆元テーブルから逆階乗 $(n!)^{-1}$
    • build_finv_using_fact: 階乗テーブルから逆階乗 $(n!)^{-1}$
  • クエリ（対応するテーブルが構築済みのときのみ型で呼び出し可能）
    • fact, finv, inv, binom

§例

use fp::fp_new;
use fp_precalc::Precalc;
const P: u64 = 1009;
let pc = Precalc::<P>::new(100).build_fact().build_finv_using_fact();
assert_eq!(pc.binom(5, 2), fp_new::<P>(10)); // C(5,2) = 10

§計算量

  • build_fact, build_inv, build_finv_using_inv, build_finv_using_fact: $O(n)$
  • fact, finv, inv, binom: $O(1)$
