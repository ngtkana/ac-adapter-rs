Expand description

スライス $A$ の累積和・その逆変換をまとめたトレイト。全て破壊的（in-place）に書き換える。

§例

use riff::SliceAccum;
let mut a = [1, 2, 3, 4, 5];
a.prefix_sum();
assert_eq!(a, [1, 3, 6, 10, 15]);
a.prefix_sum_inv();
assert_eq!(a, [1, 2, 3, 4, 5]);

fn prefix_sum(&mut self)

累積和に変換する：$A_i \gets \sum_{j=0}^{i} A_j$。

Source

fn prefix_sum_inv(&mut self)
where for<'a> T: SubAssign<&'a T>,

prefix_sum の逆変換：$A_i \gets A_i - A_{i-1}$（$A_{-1} = 0$）。

Source

fn suffix_sum(&mut self)
where for<'a> T: AddAssign<&'a T>,

逆順の累積和に変換する：$A_i \gets \sum_{j=i}^{n-1} A_j$。

Source

fn suffix_sum_inv(&mut self)
where for<'a> T: SubAssign<&'a T>,

suffix_sum の逆変換：$A_i \gets A_i - A_{i+1}$（$A_n = 0$）。
