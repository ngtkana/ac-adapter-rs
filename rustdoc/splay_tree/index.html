挿入・削除・区間反転・区間作用・区間畳み込みに対応した平衡二分探索木（スプレー木）。

要素を現在の並び順の添字（0-indexed）でアクセスする、配列を模した木構造。ノードに モノイド $(Acc, \cdot)$ の集約値と、値・集約値へ作用する $Lazy$ を持たせ、遅延伝播で 管理する。任意位置へアクセスするたびに対象ノードを回転で根まで引き上げる「スプレー」 操作を行うことで、平衡条件を明示的に保たなくてもならし $O(\log n)$ でアクセス・分割・ 併合ができる。

§仕様

LazyOps トレイトで集約 $Acc$ と作用 $Lazy$ を定義し、SplayTree<O> を使う。

  • proj, op: 値 $\to$ 集約値の変換と、集約どうしの積（結合律が必要）
  • act_value, act_acc, compose: 値・集約値への作用と作用の合成
  • 作用が不要なら Ops を実装して NoLazy でラップする
  • 集約も作用も不要なら Nop をそのまま使う

主な操作：

  • insert, remove: 添字を指定した挿入・削除
  • reverse: 区間 $[l, r)$ の反転
  • act: 区間 $[l, r)$ への作用の適用
  • fold: 区間 $[l, r)$ の集約値の取得
  • get, entry: 1点の参照・書き換え
  • split_off, append: 木の分割・併合

§例

use splay_tree::NoLazy;
use splay_tree::Ops;
use splay_tree::SplayTree;

enum Sum {}
impl Ops for Sum {
    type Value = i32;
    type Acc = i32;
    fn proj(&x: &i32) -> i32 {
        x
    }
    fn op(&x: &i32, &y: &i32) -> i32 {
        x + y
    }
}

let mut splay = (0..5).collect::<SplayTree<NoLazy<Sum>>>();
splay.insert(2, 100);
assert_eq!(splay.iter().copied().collect::<Vec<_>>(), vec![
    0, 1, 100, 2, 3, 4
]);
assert_eq!(splay.fold(..), Some(0 + 1 + 100 + 2 + 3 + 4));

§計算量

  • insert, remove, get, entry: ならし $O(\log n)$
  • reverse, act, fold: ならし $O(\log n)$
  • split_off, append: ならし $O(\log n)$

Structs§

Entry
SplayTree::entry が返す、要素への可変ハンドル。Deref/DerefMut で値にアクセスする。
Iter
SplayTree::iter, SplayTree::range が返すイテレータ。
NoLazy
Ops を実装する型を、作用なしの LazyOps に変換するラッパー型。
Nop
集約も作用も行わない場合に使う LazyOps 実装。要素の並びを管理するだけでよいときに使う。
SplayTree
挿入・削除・区間操作に対応したスプレー木本体。モジュールレベルの説明を参照。

Traits§

LazyOps
集約と、集約・値への作用を定義するトレイト。SplayTree の要素型・集約型・作用型を決める。
Ops
作用（更新）を持たない、集約だけを定義するトレイト。NoLazy でラップすると LazyOps になる。
Value
Sized + Debug + Clone をまとめたトレイト境界。LazyOps の関連型はすべてこれを要求する。
