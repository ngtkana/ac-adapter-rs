Crate jagged_iterator

Source
Expand description

多次元コンテナの要素をインデックス配列付きで列挙するイテレータ。

Vec<Vec<T>> のように入れ子になったコンテナを再帰的に辿り、各要素とそこに至るまでの 添字列を組にして返す。次元数はコンパイル時定数 D として持ち、添字は Vec ではなく 固定長配列 [usize; D] で返すためアロケーションが発生しない。D = 1 から D = 8 までの 実装をマクロで生成しており、Vec に限らず配列・スライス・VecDeque など、ネストした IntoIterator になっている型であれば利用できる。

§仕様

  • トレイト: JaggedIterator<'a, const D: usize>
  • メソッド: jagged_enumerate(&'a self) -> impl Iterator<Item = ([usize; D], Item)>
  • 対応する次元数: $D = 1, \ldots, 8$
  • 内側の型自体が Copy（固定長配列など）だと複数の D が実装候補になり型推論できない ことがある。その場合は JaggedIterator::<D>::jagged_enumerate(&x) とフルパス指定する

§例

use jagged_iterator::JaggedIterator;

let v = vec![vec![1, 2], vec![3]];
let result = v.jagged_enumerate().collect::<Vec<_>>();
assert_eq!(result, vec![([0, 0], 1), ([0, 1], 2), ([1, 0], 3)]);

§計算量

  • jagged_enumerate: $O(n)$（$n$ は総要素数）
