**ルール**: 文章は短く、文法より簡潔性を優先する

**適用範囲:**
- レポート・ドキュメント
- コメント
- 説明文
- 出力結果

**具体例:**

❌ 不要：
```
テストケースについては、10桁と20桁の2つのケースを用意しました。
これらは一般的な使用ケースと最大値に近いケースを代表するものです。
```

✅ 推奨：
```
テストケース: 10桁, 20桁
```

**Why:** プロジェクトの効率性。読み手は実装者で、背景説明より結果を求める

**How to apply:** 削除可能な単語は削除。接続詞・修飾詞を最小化。表・リストで構造化。
